## [Unreleased]

### Added
- «+ инструмент» двумя путями по природе партии: мелодические (флейта, орган,
  сакс, гитара, синт, пиано) — овердабом, цельным ре-рендером того же плана
  (ритм и гармония совпадают всегда; локализация — фразой в стиле по позиции
  выделения; сид родителя = та же интерпретация), подклады (струнные,
  колокольчики) — вклейкой куска в выделение.
- `seed` в `POST /jobs/{id}/overdub` — овердаб «та же интерпретация», ближе
  к оригиналу (MCP `overdub.seed`).
- Громкость вклеек инструментов: ползунок в дБ у каждой вклейки (−24…+6,
  по умолчанию −6); уровень партии сначала выравнивается по окну оригинала.
  Трек пересобирается со всеми вклейками с чистого оригинала — без наслоения.
- `cmd/yue-align` — замер синхронности вклейки с треком (ошибка в мс).

### Fixed
- Вклейка инструмента (струнные, колокольчики) звучала на такт позже выделения:
  мини-рендер начинается с такта контекста, теперь его начало ставится на
  from − lead. Партия подгоняется по бочке трека (стем drums, ±¼ доли); если
  подгонка не уверена — встаёт по сетке плана с пометкой «по плану».
- Честный прогресс генерации: процент считается только по семантическим токенам
  (раньше смешивались с токенами плана — полба доезжала до 99% задолго до конца);
  после генерации — стадия «сохранение…». Жёсткий потолок длины из селектора
  длительности (`max_tokens` в POST /jobs: «1–2 мин» ≈ 3000 токенов) —
  инструментал больше не раздувается до 5+ минут.

### Added
- Управление вариантами: «✕» — удалить вариант эффекта/вклейки с сервера
  (`DELETE /jobs/{id}/dsp/{file}`, MCP `dsp_variant_delete`); выпадающие селекты
  не растягивают страницу (высота по месту на экране).
- Вариант DSP-эффекта — отдельным треком: кнопка «→ в треки» в строке варианта
  («{трек} · {эффект}», `POST /jobs/{id}/variant_track`); рядом «⤓» — сохранить файлом.
  Починен z-index выпадающих селектов поверх последующих строк (эффекты).
- «+ инструмент» — локально и надёжно: вместо стилевой приписки (расползалась на весь
  трек) инструмент рендерится отдельной овердаб-партией по плану, где он молчит вне
  выделения, и подмикшируется под оригинал (`overdub-*.flac`, играет в студии сам);
  овердаб воркера принял параметр `abc`.
- Приёмы на ролле (студия): «поломки» плана по выделенным тактам без знания нот —
  заимствованный аккорд (мрачнее/светлее/напряжённее от тональности), провал-пауза,
  вырезание тактов, вокал ±октава, «+ инструмент» в выбранную секцию (флейта/струнные/
  орган/сакс/электрогитара/синт/колокольчики/пиано — стилевой припиской), темп ±10%
  от выбранного места (Q: в плане, накапливается). Правки накапливаются без генерации
  (метки на ролле), пересборка — одной кнопкой с сохранением стиля/лирики/seed;
  «▶ проверить кусок» — мини-рендер места с правками, играет прямо в студии;
  «✦ черновик» — быстрая проба начала; «✕ убрать в выделении / сбросить» — снятие
  правок и меток. Статусы генерации — с прогрессом прямо в студии. Метки
  наследуются новыми версиями.
- Примерочная голосов (страница «Голоса»): ручки характера (регистр, грубость, скрипучесть,
  подача, дыхание + своё описание) → дескриптор вокала, прослушивание ~18 с на нейтральном
  стенде, карточки голосов с seed — «в форму» переносит голос в новый трек. Карточки
  хранятся на воркере (`POST/GET/DELETE /voices`, копия аудио переживает удаление джоб);
  MCP-инструменты `voices_list` / `voice_create` / `voice_delete`.
- Группа стилей «Альт-рок / гитарная гармония»: тёмный пост-панк с интерлок-арпеджио,
  арт-рок с sus/add9-аккордами, альт-рок с chorus-гитарами, гараж-блюз-дуэт — каждый
  стиль в двух вариантах, с вокалом и без слов.
- Драматургия трека (`arc` в `POST /jobs`): нарастание / волна / взрыв — дуга темпа по
  секциям плана, для «взрыва» голос в финальном припеве поднимается на октаву
  (экспрессия исполнителем, не громкостью). Чипы «драматургия» в форме, MCP `submit.arc`.

## [0.1.1] - 2026-09-27

### Added
- Лирика: распознавание текста трека (faster-whisper, `POST /lyrics`) и адаптация-перевод
  под пение с сохранением слоговой сетки (`POST /lyrics/adapt`, Ollama) — кнопки «♪ из трека»
  и «→ русский» у поля лирики. Каверы на другом языке без абракадабры.
- Лирика из джобы: `POST /jobs/{id}/lyrics` — whisper по готовому аудио джобы,
  без повторной загрузки файла (кнопка «♪ текст этого трека» в овердабе, MCP `job_lyrics`).
- Овердаб: поле лирики — голос поёт заданный текст вместо импровизированного вокализа
  (`lyrics` в `POST /jobs/{id}/overdub`, UI-поле, MCP-инструмент).

### Fixed
- mp3-конвертация воркера: planar-буфер вместо interleaved ускорял каждый канал
  в 2 раза (левый, затем правый) — скачивание в mp3 давало «скоро́ренный» звук.

## [0.1.0] - 2026-09-27

Первый публичный релиз: desktop-приложение генерации музыки на YuE2-3B
(Wails: Go + Vue 3) с GPU-воркером (FastAPI), MCP-сервером для AI-агентов и полным
рабочим флоу от строки стиля до готового трека.

### Added
- Генерация: форма-слоты стиля на русском (словарь + автоперевод через Ollama),
  библиотека 100+ откалиброванных стилей с группами и своими коллекциями,
  веер best-of-N по сидам, стадия плана (ABC) с правкой до рендера, каверы по чужим
  трекам (транскрипция SheetSage2)
- Режим «черновик» ~18 с: быстрое предпрослушивание стиля до полного рендера;
  полный рендер с тем же сидом продолжает траекторию
- Очередь с живым прогрессом (стадия, токены, процент) и отменой — в том числе
  уже идущей генерации
- Студия трека: пиано-ролл партитуры с превью фрагментов (VAE-decode), стемы
  (demucs), минус-треки, овердаб, DSP-цепочки эффектов (ffmpeg на ПК) с метриками
  и дельтами до референсов/других джоб
- Профили исполнителей из корпусов треков: тональности/прогрессии/темп/структура
  (SheetSage2) + тексты (faster-whisper) + строка стиля (Ollama)
- Копайтер стихов (Ollama); интерфейс на русском и английском
- MCP-сервер `yue-mcp` (31 инструмент): весь рабочий флоу, настройки, библиотека,
  диагностика и установка воркера (локально или по ssh) — для Claude/Codex/др.
- Настройка длины и характера генерации: `YUE2_MAX_TOKENS` (до ~10 мин),
  `YUE2_CFG_SCALE`
- Инфраструктура: MIT-лицензия, CI (линтеры + тесты + сборка всех трёх стеков),
  спецификационные тесты (Go/vitest/unittest), Makefile, документация

### Fixed
- Громкость плеера на Windows применялась некорректно
- Перемотка плеера: длительность урезалась остатком — ползунок улетал за конец;
  позиция теперь всегда абсолютная
- Парсер ABC считал аккорды в кавычках нотами — смещался таймлайн пиано-ролла
- Кеш весов терялся при деплое (HF_HOME в юните) — воркер качал веса заново
