# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — SemVer.

> **Правило:** записи ведём начиная с первой версии `v0.1.0` (ещё не вышла — до неё
> раздел `Unreleased` не заполняем). После её выхода: заметные изменения добавляются
> в `Unreleased` по ходу разработки, а при релизе (тег `vX.Y.Z`) раздел переименовывается
> в версию с датой (группировка Added / Changed / Fixed / Removed). Запись в changelog —
> обязательный шаг релиза, равный тегу.
