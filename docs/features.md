# Возможности Yue Studio

Что умеет приложение, коротко и по шагам работы. Подробности — по ссылкам: интерфейс —
[ui-guide.md](ui-guide.md), эффекты — [effects.md](effects.md), управление через AI-агента —
[mcp.md](mcp.md), чего сделать нельзя — [limitations.md](limitations.md).

## 1. Придумать песню

- **Форма-слоты стиля** на русском: жанр, ритм, гитары, голос, настроение, звучание. При
  отправке подсказки превращаются в английские теги YuE, свой текст переводит Ollama.
- **Стойка инструментов** — карточки с примочками, галочки сами дописываются в стиль.
- **Библиотека стилей** — 27 групп, больше 100 откалиброванных стилей; можно вставить
  точную строку калибровки («1:1»).
- **Профили исполнителей** — свой стиль из 3–10 треков одного исполнителя: темп,
  тональность, аккорды, структура → строка стиля и партитура.
- **Стих** с тегами секций (`[Verse] [Chorus]…`), пометки `#` не поются; копайтер стихов
  через Ollama.

Подробно: [ui-guide.md — левая колонка](ui-guide.md#левая-колонка).

## 2. Сгенерировать

- **В очередь** — одна генерация; **×5 сидов** — пять вариантов сразу, лучший выбирается
  на слух.
- **План (ABC)** — партитура за секунды, до синтеза звука: можно поправить мелодию под
  ударения стиха и рендерить уже по своим нотам. Как — [lyrics-melody.md](lyrics-melody.md).
- **Кавер / мелодия чужого трека** — «Из трека…»: транскрипция в ABC (SheetSage2).
- **Импорт своего трека** (страница «Свои треки»: flac/mp3/wav/ogg/m4a) — в его студии работают
  стемы, минус, эффекты, ролл по транскрипции и овердаб.
- Очередь с отменой и прогрессом, папки («Альбом», «Основы», «Эксперименты», свои),
  свои названия треков, прослушивание во встроенном плеере или в браузере.

## 3. Доработать в студии

Студия трека открывается из карточки готовой джобы. Подробно —
[ui-guide.md — правая колонка](ui-guide.md#правая-колонка-очередь-и-результаты).

- **Пиано-ролл** — такты × голоса, аккорды, секции; превью любого фрагмента за секунды.
- **Волна и спектр** — видно удары, провалы, вступления; клик — слушать с места, протяжка —
  выделение для правок.
- **Приёмы без генерации** — «не тот аккорд», «провал», «вырезать такты», «голос ±октава»,
  «+ инструмент», «темп ±10 %»; «проверить кусок» — мини-рендер, «пересобрать трек» — всё разом.
- **Голос по частям** — «голос выше», «вариации», «перепеть с места» (новые дубли голоса только
  в выделенной части), «голос: стоп».
- **Стемы** (demucs): голос, барабаны, бас, «прочее», отдельно гитара и клавиши; **минус** без голоса.
- **Вклейки и пересборка** — кусок, перерендеренный моделью, ложится в трек только нужными
  дорожками, в ритм по бочке; громкость и глушение дорожек в окне.
- **Громкость по волне** — линия громкости для всего трека или одной дорожки.
- **Эффекты** — 53 цепочки: пространство (реверб, дилей, ширина), модуляция, фильтры, динамика,
  темп и высота, глитч, лоуфай, примочки на голос, гитарные педали; на весь трек или на дорожку
  в окне, мастеринг одним кликом. **Превью места** с «было / стало» — до применения, за пару
  секунд. Все эффекты и как ими пользоваться — **[effects.md](effects.md)**.
- **🎸 Педали** — доска гитарных эффектов по порядку: готовые наборы, перестановка, вкл/выкл,
  сравнение до четырёх вариантов на одном куске; подобрать звук гитары, прежде чем просить его
  у модели. Подробно — [effects.md — педали](effects.md#педали-и-педалборд).
- **Овердаб** — партия по партитуре трека с новым стилем, смешанная с оригиналом.
- **Голос альбома** (эксперимент) — голос трека тембром другой песни (Seed-VC).
- **Метрики** — громкость (LUFS), динамика, стерео, спектр; у каждого варианта — дельта к исходнику.

Результат любой правки — вариант или новая версия песни: исходник не меняется, лучшая версия
делается основной («☆»).

- **Дорожки** — пульт в шаге «Звук»: строка на каждую дорожку, свой звук ей (готовая или своя цепочка движка),
  «было/стало» на выделении; **Правки трека** — выключить, удалить, изменить любую правку.
- **Пресеты звука** — рецепт обработки трека целиком (замена барабанов, бас, эквалайзеры дорожек, финал):
  выбрать в форме нового трека (до трёх — версии «трек · пресет» появятся сами, когда трек готов), применить
  в студии к любому треку или сохранить свои правки «весь трек» как пресет. Встроенные — «Пост-панк ·
  Transmission», «Инди-рок · Sex on Fire» и «Живая ритм-секция» (все барабаны и бас сэмплами, тамы по высоте).

## 4. Отдать

- Сохранить вариант файлом («⤓» у варианта) или стем («⤓» у дорожки); через агента —
  `artifacts` отдаёт путь к файлу.
- Выровнять громкость треков альбома — эффект «Громкость альбома».

## 5. Всё то же через AI-агента

MCP-сервер даёт агенту (Claude, Codex) весь рабочий флоу: генерацию, студию, эффекты, установку
и диагностику. Список инструментов и настройка — [mcp.md](mcp.md).

## Под капотом

- Приложение (Wails: Go + Vue) — на ПК; генерация — на GPU-машине (воркер FastAPI + YuE2), по сети.
  Эффекты считаются на ПК локальным ffmpeg. Схема — [architecture.md](architecture.md).
- Установка воркера, системные требования, деплой — [deployment.md](deployment.md).
- HTTP API воркера — [api.md](api.md).
