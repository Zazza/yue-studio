# Архитектура Yue Studio

## Общая схема

```
┌─────────────────────────────┐         HTTP (локальная сеть)
│  ПК: desktop-приложение     │ ──────────────────────────────┐
│  Wails v2 (Go + Vue 3)      │                               ▼
│  /srv/yue-studio            │                    ┌────────────────────┐
└─────────────────────────────┘                    │ GPU-машина         │
   • окно = webview (Vue)                          │ воркер FastAPI     │
   • вся логика на Go (app.go)                     │ :8091              │
   • звук = pw-play (PipeWire),                    │ резидентная YuE2   │
     т.к. в webview (webkit2gtk)                   │ + SheetSage2       │
     аудиовыхода нет                               │ + demucs           │
   • ffmpeg-цепочки DSP — локально                 │ + Ollama           │
                                                   │ + faster-whisper   │
                                                   └────────────────────┘
```

Два независимых процесса: закрытие приложения не прерывает генерации —
очередь живёт на GPU-машине в SQLite (`~/yue-studio/data/yue.db`).

## Сторона ПК (репозиторий)

| Файл/каталог | Роль |
|---|---|
| `main.go` | запуск Wails, встраивание фронта, прокси `/audio/...` на воркер |
| `app.go` | биндинги для Vue (Yue*) — тонкие обёртки над клиентом |
| `player.go` | встроенный плеер: pw-play + SIGSTOP/SIGCONT (пауза) |
| `internal/yue/client.go` | HTTP-клиент воркера: jobs, plan, transcribe, corpus, стемы… |
| `internal/dsp/` | ffmpeg-цепочки эффектов (локальные, на готовом flac) |
| `internal/studio/` | вклейки инструментов: пересборка трека со всеми вклейками с чистого `audio.flac`, партия ставится в ритм по бочке (стем drums), громкость — дБ к уровню окна |
| `cmd/yue-align` | замер синхронности вклейки: сдвиг/скорость партии против окна трека, ошибка в мс |
| `frontend/src/App.vue` | весь UI (один компонент) |
| `frontend/src/presets.js` | библиотека пресетов стилей |
| `frontend/src/rack.js` | инструментальная стойка |
| `deploy.sh` | `worker` = scp+рестарт на GPU-машине; `build` = сборка приложения |

## Сторона GPU-машины (воркер)

| Файл | Роль |
|---|---|
| `yue_worker.py` | FastAPI :8091, очередь SQLite, все эндпоинты, микс овердаба |
| `dsp.py` | librosa-анализатор (метрики) |
| `sheetsage.py` | SheetSage2 (транскрипция трека → ABC, m-a-p/SheetSage2, 57M) |
| `stems.py` | demucs htdemucs (разделение на стемы, грузится на вызов) |
| `abcparse.py` | парсер score.abc → таймлайн для пиано-ролла |
| `whisper_run.py` | скрипт текста песни; запускается `~/whisper-venv`-интерпретатором |

Данные: `~/yue-studio/data/jobs/<id>/` — audio.flac/mp3/wav, score.abc,
request.abc, latent.npy (25 кадров/с — для превью фрагментов), semantic.npy,
metrics.json, dsp-*/overdub-*/preview-*/stem-*.flac. Профили корпусов —
`data/corpus/<id>/`.

## Конвейер генерации YuE2

Стадии (внутри yue2): план (ABC-партитура) → семантические токены (AR,
слева-направо) → латенты (NAR flow-matching) → VAE-decode (чанковый).

Отсюда ключевые следствия:
- **правка середины сдвигает хвост** — точечных правок нет, каждый вариант
  полного пересбор (~минута GPU);
- **превью фрагмента дёшево**: латенты сохранены, кусок 146-секундного трека
  декодируется за секунды без AR-генерации;
- **инструменты определяет строка стиля**, не ABC: в партитуре только голоса
  Vocal/Ins.

## VRAM (16 ГБ, делится с Ollama)

- YuE2 резидентна (~7.7 ГБ) — держится загруженной между запросами.
- SheetSage2 мала (сотни МБ) — тоже резидентна, отдельный лок.
- demucs ~0.7 ГБ — грузится на вызов и выгружается.
- Ollama (копайтер/перевод/профиль) вызывается с `keep_alive: 0` — выгружается
  сразу. Если Ollama держит модель — генерация падает OOM.
